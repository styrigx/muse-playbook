# Muse 玩法手册

> 全网搜罗的 Muse（Meta 个人 AI 助手）实用技巧与真实用例，共 **501 条**。
> 覆盖提问技巧、效率办公、编程开发、学习、写作、生活助手、搜索调研、创意娱乐、隐藏功能、进阶玩法十大类。

## 怎么用这本手册

- 按需查阅：每个文件是一个大类，文件内再按场景分子类
- 每条都是一句话可落地的操作，不是空话
- 标注了"网友实测"的条目来自社区用户自述，未经独立验证，效果因人而异
- 涉及花钱、发消息、删数据的操作，默认先看草稿再确认——手册里多处有权限安全提醒

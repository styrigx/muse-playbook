# Muse 玩法手册

> 全网搜罗的 Muse（Meta 个人 AI 助手）实用技巧与真实用例，共 **652 条**，每条都带怎么做和可直接复制的例子。
> 覆盖提问技巧、效率办公、编程开发、学习、写作、生活助手、搜索调研、创意娱乐、隐藏功能、进阶玩法十大类。
> 最后更新：2026-11-24（全量重写：607 条一句话版 → 652 条步骤版，见 [CHANGELOG.md](CHANGELOG.md)）。

## 怎么用这本手册

- 按需查阅：每个文件是一个大类，文件内再按场景分子类
- 每条都是可落地的操作：怎么做是步骤，例子是能直接复制的原话，注意只写真有限制或坑的地方
- 标注了"网友实测"的条目来自社区用户自述，未经独立验证，效果因人而异
- 涉及花钱、发消息、删数据的操作，默认先看草稿再确认——手册里多处有权限安全提醒

## 按场景找入口

- 刚开始用，不知道从哪下手 → 先读 [01-提问技巧](01-提问技巧.md)，再读 [09-隐藏功能](09-隐藏功能.md) 的 Soul、记忆、权限三节
- 每天重复的活想交出去（回邮件、做简报、记账）→ [02-效率办公](02-效率办公.md)
- 想让它写代码、管仓库 → [03-编程开发](03-编程开发.md)
- 备考、学语言、做研究 → [04-学习提升](04-学习提升.md) + [07-搜索调研](07-搜索调研.md)
- 写文章、做社媒、搞播客视频 → [05-写作创作](05-写作创作.md)
- 省钱、出行、家务这些生活里的事 → [06-生活助手](06-生活助手.md)
- 想玩点花的（画图、音乐、游戏、Spaces）→ [08-创意娱乐](08-创意娱乐.md) + [09-隐藏功能](09-隐藏功能.md) 的 Spaces 一节
- 已经玩顺了，想上连接器、自动化、多 agent → [10-进阶玩法](10-进阶玩法.md)
